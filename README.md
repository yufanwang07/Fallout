# Fallout Legendary Weapons

This is a work-in-progress standalone legendary weapons pack for Fallout SMP, an upcoming private invite-only Minecraft server, inspired by the legendary weapons from Altar SMP and Hoplite.

<img src="pale_blade.png" alt="pale" width="150"/><img src="the_descent.png" alt="descent" width="150"/><img src="spellblade.png" alt="spell" width="150"/>

## Weapons

- **Pale Blade**: Combo-focused sword. All attacks (including missed ones) do stacking sweeping damage.
- **The Descent**: A mace-inspired sword. Smash attacks deal damage-capped AOE damage, and teleports the user back upwards instantly (instead of wind charging upwards).
- **Archmage's Spellblade**: Right-click weapon with a charged-up single-target burst, a shift right-click AOE storm channel, and randomly chosen schools of magic.
- **Dragon Egg**: The Dragon Egg gives its holder buffs when dropped (restored after some time), including extra health, strength, etc, but permanent glowing.

## Commands

Use these commands to grant the legendary weapons directly:

```mcfunction
/function fallout_smp:give_pale_blade
/function fallout_smp:give_the_descent
/function fallout_smp:give_spellblade
```

## Features

- **Legendary Weapons Framework**: Framework for legendary weapons, including loot tables, crafting recipes, and utility functions.
- **Particles**: Flashy, but fitting all-vanilla particle effects for weapon attacks / special attacks.

## Resource Pack

Weapon models and textures live separately on the `feature/resource-pack` branch as a resource-pack zip.
